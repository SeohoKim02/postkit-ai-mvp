# PostKit AI MVP

PostKit AI는 소상공인과 1인 창작자를 위한 생성형 AI 기반 숏폼 콘텐츠 기획·대본·캡션 자동화 서비스입니다.

## 핵심 문제
소상공인과 1인 창작자는 릴스, 쇼츠, 틱톡 등 숏폼 콘텐츠를 꾸준히 만들어야 하지만 주제 선정, 대본 작성, 자막 구성, 해시태그 작성, 업로드 문구 작성에 많은 시간을 사용합니다.

## 솔루션
사용자가 업종, 상품, 홍보 목적, 원하는 분위기를 입력하면 AI가 숏폼 콘텐츠 주제, 15초/30초 영상 대본, 장면별 콘티, 자막, 해시태그, 업로드 문구를 생성합니다.

## MVP 기능
1. 가게/상품 정보 입력
2. 콘텐츠 톤 선택
3. 숏폼 주제 추천
4. 대본/자막/해시태그 생성
5. 결과 복사 및 저장

## Competition
CODEGATE 2026 AI START-UP 해커톤 예선 제출용 MVP 기획 레포지토리입니다.
